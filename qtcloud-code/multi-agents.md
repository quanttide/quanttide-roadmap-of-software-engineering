# 编程云吸收 Vicoa 编排能力意图

## 背景与动机

编程云（qtcloud-code）当前是单机 CLI 形态的质量门禁，以「约束 → AI 生成 → 校验」闭环约束 AI 编码交付质量，提供 audit、review、scaffold 等命令。它解决的是「怎么验收 AI 写的代码」，尚未解决「怎么组织一支 AI 团队写代码」。

Vicoa 是开源 AI 编排器，解决后者：在任意设备上统一调度多个编程智能体，并行写同一个仓库。Vicoa 提供「一支 AI 团队怎么组织、怎么并行、怎么盯」的范式，编程云提供「怎么验收」的范式，两者叠加即为完整的 AI 开发流水线。

## 核心意图

编程云吸收 Vicoa 四类核心功能：

| 功能 | Vicoa 的实现 | 编程云的落点 |
|------|-------------|-------------|
| 多智能体并行编排 | 同一仓库多 agent 并行，git worktree 隔离互不干扰 | 约束驱动生成从单线程走向并行：写代码、写测试、写审查各司其职 |
| 统一指挥台 | 所有会话、任务、自动化集中可见可操作 | 多 agent 并行后的任务总览与逐个干预入口 |
| 多端协同与通知 | 桌面、CLI、手机同步同一会话，决策与完成时推送 | 任务异步跑、人不在电脑前也能批 |
| BYO-key | 用户自带模型订阅与 API key，平台不锁死模型供应商 | LLM review 已走 OpenAI 兼容接口，多 agent 化后保持模型供应商无关 |

## 建设路径

- 单 agent 编排起步：先让一个 agent 在约束闭环内自主修复，验证无头运行与远程控制；
- worktree 并行化：多个 agent 分工同一仓库，互不干扰；
- 统一指挥台：会话与任务集中管理；
- 多端与通知最后做，重异步体验。
